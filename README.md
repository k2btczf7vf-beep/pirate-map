# 나의 해적 지도

첨부한 양피지 이미지 위에 자유선, 직선, 지명 등을 그리는 사이트입니다. 설치나 GitHub 로그인 없이 사용할 수 있습니다. 마우스와 터치를 지원하며, 그림과 배경을 함께 PNG로 저장합니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만드세요. 무료 GitHub Pages로 공개하려면 공개 저장소를 사용하세요.
2. 이 ZIP을 풀고 **폴더 안의 파일과 assets 폴더**를 저장소 최상위에 올리세요. 최상위에 index.html이 있어야 합니다.
3. 저장소의 Settings → Pages에서 Source를 Deploy from a branch로 선택하세요.
4. Branch를 main, 폴더를 /(root)로 선택하고 Save를 누르세요.
5. 배포가 끝나면 Pages에 표시된 주소로 접속하세요.

## 사용 방법

- 자유선/직선: 도구를 선택하고 지도 위에서 드래그하세요.
- 지우개: 배경 양피지는 유지하고 그린 내용만 지웁니다.
- 지명: 텍스트를 입력한 다음 지도에서 위치를 누르세요.
- 실행 취소: 버튼 또는 Ctrl/⌘+Z. 다시 실행: Ctrl/⌘+Shift+Z 또는 Ctrl/⌘+Y.
- PNG로 저장: 배경과 그림을 합친 이미지를 다운로드합니다.

그림은 현재 열린 페이지에서만 유지됩니다. 새로고침하거나 닫기 전에 PNG로 저장하세요. 서버에 그림을 업로드하지 않습니다.

로컬에서는 index.html을 브라우저로 열어 사용할 수 있습니다. 다운로드가 브라우저 환경에서 제한되면 로컬 서버나 GitHub Pages에서 사용하세요.

## 해적 지도 스타일

가로 양피지, 갈색 잉크, 고풍스러운 테두리를 기본으로 사용합니다. 해안선 도구는 섬 윤곽 주위에 옅은 띠를 만들고, 항로 도구는 점선을 그립니다. 지도 배경에서 참고 지도를 선택하면 두 번째 첨부 이미지 위에 그릴 수도 있습니다. 산, 숲, 배 등의 일러스트 스탬프는 포함되어 있지 않습니다.
